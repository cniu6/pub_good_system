# scripts 目录留档

> **最后更新**：2026-07-16

## 简介

存放可选运维/构建辅助脚本。当前仓库主流程脚本在**项目根**：

| 根脚本 | 作用 |
|--------|------|
| `dev.bat` | 开发：前端 + 根目录后端 |
| `build.bat` | 生产构建（含 embedded 等） |
| `test.bat` | 测试入口 |

`scripts/` 目录若为空或仅有本地临时脚本，以实际文件为准；新增脚本请在此文档补充说明与调用示例。

## 规范

- Windows 环境注意 `-utf8` / `chcp 65001`。
- 脚本内不要写死生产密钥；从 `.env` 或参数读取。
