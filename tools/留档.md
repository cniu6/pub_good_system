# tools 目录留档

> **最后更新**：2026-07-16

## 简介

命令行辅助工具，**不挂入 Web 服务**。在项目根或对应子目录执行。

## 子工具

| 目录 | 说明 | 文档 |
|------|------|------|
| `register_admin/` | 注册/创建管理员账号 | [register_admin/README.md](./register_admin/README.md) |
| `reset_password/` | 重置用户密码 | [reset_password/README.md](./reset_password/README.md) |

## 使用注意

- 需要能连上与主程序相同的数据库（读根 `.env` 或工具自身配置，以各工具 README 为准）。
- 生产环境操作前备份数据。
- 勿把含真实密码的命令历史提交到仓库。
