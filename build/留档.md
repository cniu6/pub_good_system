# build 目录留档

> **最后更新**：2026-07-16

## 简介

`build.bat` 等构建产物输出目录。具体子目录可能包含：

- Windows / Linux 二进制（`fst.exe` 等）
- 复制的 `.env.example`
- embedded 静态资源相关产物

## 版本控制

- 大体积二进制一般被 `.gitignore` 忽略（见根 `.gitignore` 的 `build/*/fst*` 等规则）。
- 本目录仅作本地/CI 输出；**不要**把含真实密钥的配置打进分发包。
