# 程序启动入口与资源托管 (CMD)

> 路径：`backend/cmd/`  
> **最后更新**：2026-08-09

## 本目录只留服务进程

| 路径 | 用途 |
|------|------|
| [`server/`](./server/) | 进程薄壳：调 appinit + 前端托管 + Listen |

运维/清理/诊断脚本已挪到项目根 [`tools/`](../../tools/)。

## 启动链路

```text
根 main / main_embedded
  → cmd/server.Start
  → internal/appinit.Bootstrap / SetupHTTP
  → internal/migrate.RunAutoMigrate
```

## 日常运行

```bash
go run ./main.go
# 或
go run .
```

打包：`build.bat`（`-tags embedded`，`-ldflags "-X main.BuildMode=..."`）。
