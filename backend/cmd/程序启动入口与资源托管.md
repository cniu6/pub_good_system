# 程序启动入口与资源托管 (CMD)

> 路径：`backend/cmd/`  
> **最后更新**：2026-07-16

## 重要变更

**主入口已统一到项目根目录**：

| 文件 | 用途 |
|------|------|
| 根 `main.go` | 开发/普通运行 |
| 根 `main_embedded.go` | 嵌入前端静态资源的单二进制 |

`backend/cmd/` 保留历史说明与部分辅助/测试代码；`.gitignore` 可能忽略旧的 `backend/cmd/main.go` 产物路径。日常请：

```bash
# 项目根
go run ./main.go
# 或
go run .
```

## 启动时能力（概念）

- 加载配置、DB、迁移  
- 后台任务（如验证码清理 `StartCleanupTask`）  
- `SetupRoutes` + 监听端口  
- embedded 模式下静态资源托管  

### 验证码清理

- 间隔：`CLEANUP_INTERVAL_MINUTES`（默认 10）  
- 状态：`GET /api/v1/system/cleanup-status`  

## 规范

- 端口可配置（`.env` 的 `PORT`）  
- 优雅关闭（HTTP shutdown timeout 可配）  
- 勿再把新主逻辑只写在 `backend/cmd` 而忽略根入口
