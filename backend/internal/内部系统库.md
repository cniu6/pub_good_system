# 内部系统库 (Internal)

> 路径：`backend/internal/`  
> **最后更新**：2026-07-16

## 简介

内部包：启动编排、初始化等。**注意**：历史上 config/db/middleware 曾放 internal，**当前主实现在 `backend/pkg/`**：

| 能力 | 当前路径 |
|------|----------|
| 配置 | `backend/pkg/config` |
| 数据库 | `backend/pkg/db` |
| 中间件 | `backend/pkg/middleware` |
| 插件注册表 | `backend/pkg/pluginregistry` |

`internal/` 主要用于 `appinit` 等启动编排（JWT 配置应用、依赖注入顺序等），请以目录内源码为准。

## 启动链路（概念）

```text
根 main.go
  → 加载 .env / InitConfig
  → 初始化 DB / Migrate
  → 应用运行时配置、JWT 等
  → SetupRoutes
  → HTTP Listen
```

## 规范

- 新横切能力优先放 `pkg/`，便于 routes/services 引用。
- 数据库表/字段一律小写+下划线。
- 文档与实现冲突时以源码为准，并回写本留档。
