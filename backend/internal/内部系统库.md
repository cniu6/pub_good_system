# 内部系统库 (Internal)

> 路径：`backend/internal/`  
> **最后更新**：2026-07-17

## internal 放什么？

**只放本仓库用的系统骨架**：

| 路径 | 放什么 |
|------|--------|
| `appinit/` | 启动编排：`Bootstrap` + `SetupHTTP` |
| `migrate/` | 全部数据库自迁移 |
| `task/` | **自动任务管理器核心**（SQL 定义/执行记录/内存缓存/调度/handler） |

**不要放**：controllers / 业务 services / 路由表（那些在 `app/`、`routes/`）。

## 和 pkg 是否重叠？

不重叠：`pkg` = 零件；`internal` = 开机组装（含建表、任务调度）。

## 启动链路

```text
根 main / main_embedded
  → cmd/server.Start
  → appinit.Bootstrap
       → config / db.InitDB
       → migrate.RunAutoMigrate
       → InitSettings / InitSMS
       → services.StartBackgroundTasks → task.Start
  → appinit.SetupHTTP
```

## 自动任务（internal/task）

- 表：`auto_job_definitions` / `auto_job_runs`
- 包结构：`types` / `handlers` / `seed` / `config` / `definition` / `run` / `stuck` / `overview` / `runtime`
- 详细说明：[task/留档.md](./task/留档.md)
- 管理 API：`app/controllers/admin/auto_job_controller.go` → `/api/v1/{ADMIN}/auto-jobs/*`
- 启动：空表导入默认任务；定义进内存；调度空跑成功不落库；id 逼近上限时重编号
- 管理前端：`frontend/src/views/admin/auto-jobs/`

## 规范

- 新启动步骤 → `appinit`
- 新表 → `migrate`
- 新后台周期任务 → `internal/task` 的 `handlers.go` + `seed.go`
- 管理系统 API → 继续 `app/`
