# 内部系统库 (Internal)

> 路径：`backend/internal/`  
> **最后更新**：2026-07-16

## 简介

内部包分两层，**不要混用**：

| 用途 | 路径 | 状态 |
|------|------|------|
| **现网**配置/库/中间件 | `backend/pkg/config` `pkg/db` `pkg/middleware` | 现网使用 |
| **平行草稿栈**启动/路由 | `appinit/` `ginweb/` `db/` `env/` `middleware/` | 现网 **不 import** |

### 【已注释禁用·留档】电商半成品

- `ginweb`：products / categories / orders 路由 **已注释**  
- `appinit.AutoMigrate`：Product / Category / Order **已注释**  
- 完整说明：[backend/留档.md](../留档.md) →「电商半成品草稿（已注释禁用）」

## 启动链路（概念）

```text
现网：根 main.go → pkg/config → pkg/db → routes.SetupRoutes → Listen

草稿（不默认启动）：appinit.Start → 注释禁用电商迁移 → ginweb（电商路由已注释）
```

## 规范

- 新横切能力优先放 `pkg/`，便于 routes/services 引用。
- 数据库表/字段一律小写+下划线。
- 文档与实现冲突时以源码为准，并回写本留档。
