# 通用工具函数库 (Utils)

> 路径：`backend/utils/`  
> **最后更新**：2026-07-23

仅后端通用工具。前端工具在 `frontend/src/utils/`，勿混写。

| 模块 | 说明 |
|------|------|
| `response.go` | `Success` / `Fail`；业务码 400–599 同时作 HTTP 状态码 |
| `jwt.go` | Access / Refresh Token 签发与解析 |
| `email.go` | 邮件发送（可走代理） |
| `password.go` | bcrypt |
| `phone.go` / `dial_codes.go` | 手机号规范化与区号 |
| `certificate.go` | 证件号掩码 `MaskCertificateNo` |
| `totp.go` | TOTP 校验 |
| `geetest.go` | 极验 |
| `proxy_*.go` | 出站代理拨号 |
| `balance_utils.go` | 余额变动事务封装 |

详细业务文档见 `doc/`。
