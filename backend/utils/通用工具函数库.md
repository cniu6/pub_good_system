# 通用工具函数库 (Utils)

> 路径：`backend/utils/`  
> **最后更新**：2026-08-09

仅后端通用工具。前端工具在 `frontend/src/utils/`，勿混写。

| 模块 | 说明 |
|------|------|
| `response.go` | `Success` / `Fail`；业务码 400–599 同时作 HTTP 状态码；返回 message 统一英文 |
| `jwt.go` | Access / Refresh Token 签发与解析 |
| `email.go` | 邮件发送（可走代理） |
| `password.go` | bcrypt、密码复杂度校验 |
| `phone.go` / `dial_codes.go` | 手机号规范化、区号数据 |
| `certificate.go` | 证件号掩码 `MaskCertificateNo` |
| `geetest.go` | 极验行为验证码校验 |
| `proxy_*.go` | 出站代理拨号 |
| `balance_utils.go` | 余额变动事务封装 |
| `money.go` | 金额/分转换与校验 |
| `pagination.go` | 分页参数规范化 |
| `field_limit.go` | 字符串长度校验 |
| `http_server.go` | 统一 HTTP Server 构造（含超时配置） |
| `request_context.go` | 请求上下文辅助（IP、UA、请求 ID 等） |
| `validate.go` | 通用校验辅助 |
| `convert.go` | 类型转换辅助 |
| `code_send_limiter.go` | 验证码发送频率限制 |
| `pii_crypto.go` | PII 加密 / JWT Secret 检查 |

详细业务文档见 `doc/`。
