# 数据库连接 (DB)

> 路径：`backend/pkg/db/`  
> **最后更新**：2026-07-18

## 简介

只管**连接与连接池**、表结构探测，以及 SQLite 下的 MySQL DDL 轻量适配。  
**建表 / 自迁移**统一在 `backend/internal/migrate.RunAutoMigrate`。

## 驱动

| `DB_DRIVER` | 说明 |
|-------------|------|
| `mysql`（默认） | 生产推荐；连不上时**不会**自动切库，只会打印 SQLite 配置指引 |
| `sqlite` / `sqlite3` | 本地临时缓解；纯 Go 驱动 `modernc.org/sqlite`，数据文件见 `DB_PATH` |

## 函数

| 函数 | 说明 |
|------|------|
| `InitDB` | 建立 sqlx 连接 + 连接池（不迁移） |
| `Exec` | 执行 SQL；SQLite 下自动适配常见 MySQL DDL |
| `GetDB` | 取全局 `*sqlx.DB` |
| `IsSQLite` / `IsMySQL` / `DriverName` | 当前驱动判断 |
| `CheckTableExists` / `CheckColumnExists` / `CheckIndexExists` | 表结构探测（MySQL 用 information_schema，SQLite 用 sqlite_master/pragma） |
| `EnsureIndex` | 缺索引时执行 ALTER/CREATE |

DSN 等来自 `pkg/config`（`buildDSN` / `buildSQLiteDSN`）。
