# 数据库连接 (DB)

> 路径：`backend/pkg/db/`  
> **最后更新**：2026-07-17

## 简介

只管**连接与连接池**，以及表结构探测辅助函数。  
**建表 / 自迁移**统一在 `backend/internal/migrate.RunAutoMigrate`。

## 函数

| 函数 | 说明 |
|------|------|
| `InitDB` | 建立 sqlx 连接 + 连接池（不迁移） |
| `GetDB` | 取全局 `*sqlx.DB` |
| `CheckTableExists` / `CheckColumnExists` / `CheckIndexExists` | information_schema 探测 |
| `EnsureIndex` | 缺索引时执行 ALTER |

DSN 等来自 `pkg/config`。
