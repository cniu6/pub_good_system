# 数据库连接 (DB)

> 路径：`backend/pkg/db/`  
> **最后更新**：2026-08-09

## 简介

只管**连接与连接池**、表结构探测（Migrator）、GORM 小工具。  
**建表 / 自迁移**统一在 `backend/internal/migrate.RunAutoMigrate`（`db.DB.AutoMigrate` + 种子/补丁）。

## 驱动

| `DB_DRIVER` | 说明 |
|-------------|------|
| `mysql`（默认） | 生产推荐；连不上时**不会**自动切库，只会打印 SQLite 配置指引 |
| `sqlite` / `sqlite3` | 本地临时缓解；`github.com/glebarez/sqlite`（纯 Go），数据文件见 `DB_SQLITE_PATH`（兼容 `DB_PATH`） |
| `postgres` / `postgresql` / `pg` | `gorm.io/driver/postgres`（底层 pgx），配置见 `DB_POSTGRES_*` |

## 函数

| 函数 | 说明 |
|------|------|
| `InitDB` | `gorm.Open` + 连接池（不迁移） |
| `GetDB` / `DB` | 全局 `*gorm.DB` |
| `SQLDB` | 底层 `*sql.DB`（Ping/Stats） |
| `WithTx` / `ForUpdate` / `MapGormNotFound` | 事务与行锁辅助 |
| `IsSQLite` / `IsMySQL` / `IsPostgres` / `DriverName` | 当前驱动判断 |
| `CheckTableExists` / `CheckColumnExists` / `CheckIndexExists` | Migrator 探测 |

DSN 来自 `pkg/config`：按 `DB_MYSQL_*` / `DB_POSTGRES_*` / `DB_SQLITE_*` 分组构建，旧 `DB_HOST` 等变量自动回退。

三库集成测试：SQLite 随 `go test ./backend/...` 常规运行；PostgreSQL / MySQL 需 `-tags integration` 并提供 `FST_PG_DSN` / `FST_MYSQL_DSN`（或 `TEST_*_DSN`）。

## 迁移

- 本包**不负责**建表/补丁；建表编排只在 `backend/internal/migrate.RunAutoMigrate`。
- 启动链路：`cmd/server.Start → appinit.Bootstrap → db.InitDB → migrate.RunAutoMigrate`。
- 空库：`AutoMigrate` 自动建表 + 种子。
- 旧库：新增表/列自动加；删除/重命名/复杂变更需写补丁函数放到 `migrate.RunAutoMigrate`。
- 已存在补丁示例：`dropObsoleteFinanceApprovalArtifacts()`、`dropObsoleteRBACArtifacts()`、`models.EnsureRealnameCertUniqueConstraint()`。
