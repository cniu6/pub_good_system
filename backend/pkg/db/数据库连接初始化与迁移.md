# 数据库连接 (DB)

> 路径：`backend/pkg/db/`  
> **最后更新**：2026-07-23

## 简介

只管**连接与连接池**、表结构探测（Migrator）、GORM 小工具。  
**建表 / 自迁移**统一在 `backend/internal/migrate.RunAutoMigrate`（`db.DB.AutoMigrate` + 种子/补丁）。

## 驱动

| `DB_DRIVER` | 说明 |
|-------------|------|
| `mysql`（默认） | 生产推荐；连不上时**不会**自动切库，只会打印 SQLite 配置指引 |
| `sqlite` / `sqlite3` | 本地临时缓解；`github.com/glebarez/sqlite`（纯 Go），数据文件见 `DB_PATH` |
| `postgres` / `postgresql` / `pg` | `gorm.io/driver/postgres`（底层 pgx） |

## 函数

| 函数 | 说明 |
|------|------|
| `InitDB` | `gorm.Open` + 连接池（不迁移） |
| `GetDB` / `DB` | 全局 `*gorm.DB` |
| `SQLDB` | 底层 `*sql.DB`（Ping/Stats） |
| `WithTx` / `ForUpdate` / `MapGormNotFound` | 事务与行锁辅助 |
| `IsSQLite` / `IsMySQL` / `IsPostgres` / `DriverName` | 当前驱动判断 |
| `CheckTableExists` / `CheckColumnExists` / `CheckIndexExists` | Migrator 探测 |

DSN 等来自 `pkg/config`（`buildDSN` / `buildSQLiteDSN`）。
