# Presence 在线心跳包

> 路径：`backend/pkg/presence/`  
> **最后更新**：2026-07-20

## 职责

WebSocket 在线状态 Hub：连接鉴权、心跳、会话登记/下线、简单限流。路由入口：`routes/ws.go` → `GET /api/v1/ws/presence`。

| 文件 | 说明 |
|------|------|
| `hub.go` | 连接集合与广播/统计 |
| `handler.go` | WS 升级与消息处理 |
| `ratelimit.go` | 连接侧限流 |

管理端列表/踢人见 `app/controllers/admin/online_controller.go`。详细说明：[doc/在线会话与Presence.md](../../../doc/在线会话与Presence.md)。
