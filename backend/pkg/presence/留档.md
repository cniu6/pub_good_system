# Presence 在线心跳包

> 路径：`backend/pkg/presence/`  
> **最后更新**：2026-07-24

## 职责

WebSocket 在线状态 Hub：连接鉴权、心跳、会话登记/下线、ticket 限流与广播前会话复核。路由入口：`routes/ws.go` → `GET /api/v1/ws/presence`。

| 文件 | 说明 |
|------|------|
| `hub.go` | 连接集合与广播/统计 |
| `handler.go` | WS 升级与消息处理 |
| `ratelimit.go` | 连接侧限流 |

管理端列表/踢人见 `app/controllers/admin/online_controller.go`。详细说明：[doc/在线会话与Presence.md](../../../doc/在线会话与Presence.md)。

## 会话收口约束

- `ws-ticket` 是短时一次性票据，不是心跳轮询接口；客户端 401 必须停止重试并退出。
- WS Upgrade 与 Hub Register 成功后，才允许按 `browser_id` 收口旧会话；建连失败不能提前踢人。
- WebSocket 心跳和 Hub 广播均复核 `user_sessions.is_active/expires_at`，防止已撤销会话继续显示在线或接收公告。
- `browser_id` 收口按用户 + auth guard；按 UA 的兼容清理只处理没有 browser_id 的历史 Web 会话，不能误伤同 UA 的其它设备。
