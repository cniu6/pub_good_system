# 全局配置管理与环境加载 (Config)

> 路径：`backend/pkg/config/`  
> **最后更新**：2026-07-16

## 简介

管理系统运行所需环境变量与基础配置。支持从项目根 `.env` 加载，并提供**并发安全**的读/写接口，供运行时热更新（如管理端改 SMTP、限流相关项后 `ApplyGlobalRuntimeConfig`）。

## 关键结构字段

| 字段 | 环境变量 | 说明 |
|------|----------|------|
| `AdminPath` | `ADMIN_PATH` | 管理**页面**入口（默认 `/system-mgr`） |
| `AdminAPIPath` | `ADMIN_API_PATH` | 管理 **REST** 前缀（默认 `/admin`） |
| `EnableSwagger` | `ENABLE_SWAGGER` | 是否挂载 `/swagger/*` |
| `EnableAdminDebugOps` | `ENABLE_ADMIN_DEBUG` | 非生产默认 true；**生产永远关闭** |
| `JWTSecret` / `AdminJWTSecret` | `JWT_SECRET` / `JWT_ADMIN_SECRET` | 签名密钥 |
| `JWTAccessExpire` / `JWTRefreshExpire` | 对应 JWT 过期秒数 | Access / Refresh TTL |
| SMTP / SMS / Geetest / HTTP 超时 | 见 `.env.example` | 邮件、短信、极验、服务超时 |

## 并发安全 API（必用）

| 函数 | 用途 |
|------|------|
| `CloneGlobalConfig()` | **只读快照**，业务读配置优先用这个 |
| `UpdateGlobalConfig(fn)` | 写锁内更新（热更新） |
| `SetGlobalConfig(cfg)` | 启动或整体替换 |
| `GetGlobalConfig()` | 兼容旧代码（注意并发语义） |
| `NormalizeAdminAPIPath(path)` | 规范化 API 前缀：`/` 开头、去尾斜杠、空则 `/admin` |
| `IsProductionMode()` | 是否生产环境 |
| `IsAdminDebugOpsEnabled()` | 是否允许 debug/pprof/重启/手动任务等 |

> 禁止在 goroutine 里直接改 `GlobalConfig` 的字段而不加锁。热更新请 `Clone` → 改副本 → `UpdateGlobalConfig`。

## 环境变量加载

- `InitConfig`：优先读项目根 `.env`（godotenv / JSON 兼容逻辑见源码）。
- 优先级：`os.Getenv` > `.env` 文件 > 代码默认值。
- 本地 `.env` 已在 `.gitignore`，提交用 `.env.example`。

## 与前端的关系

- `ADMIN_PATH` ↔ `VITE_ADMIN_BASE_PATH`（页面入口，需构建期一致）。
- `ADMIN_API_PATH` → 后端路由 + `app-config.admin_api_path` → 前端运行时 `setRuntimeAdminApiPath`。
- 前端 `VITE_ADMIN_API_PATH` 仅作 app-config 失败时的回退。

## 规范

- 密钥禁止硬编码进仓库。
- 生产 `APP_ENV`/`GO_ENV`/`GIN_MODE` 设为 production。
- 改 `ADMIN_API_PATH` 后重启后端即可生效；无需改控制器里的 Swagger 注解路径（运行时改写）。
