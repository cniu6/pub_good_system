# 鉴权与权限控制中间件 (Middleware)

> 路径：`backend/pkg/middleware/`  
> **最后更新**：2026-07-16

## 简介

拦截 HTTP 请求，处理鉴权、跨域、限流、操作/访问日志、Swagger 管理端路径改写等横切逻辑。

## 文件一览

| 文件 | 作用 |
|------|------|
| `auth.go` | JWT 校验、`AuthMiddlewareForGuard`、注入用户信息 |
| `cors.go` | 跨域 |
| `logger.go` | 请求日志（可跳过 swagger 等路径） |
| `operation_log.go` | 管理操作审计日志 |
| `api_access_log.go` | API 访问日志入库 |
| `ratelimit.go` / `dynamic_ratelimit.go` | 限流；管理端动态限流；pprof 前缀随 `ADMIN_API_PATH` |
| `idempotency.go` | 幂等键（提现审核/打款等） |
| `swagger_admin_path.go` | **运行时**改写 swagger `doc.json` 中 `/api/v1/admin` → 实际管理 API 前缀 |

## 鉴权

- `AuthMiddlewareForGuard("user", "admin")`：用户接口，user 或 admin token 均可。
- `AuthMiddlewareForGuard("admin")` + `AdminOnly()`：管理端，必须管理员。
- 校验失败必须 `c.Abort()`，统一业务错误响应。

## Swagger 管理端路径改写

```text
GET /swagger/*any
  → SwaggerAdminPathRewriteMiddleware
  → gin-swagger
```

- 仅当请求路径以 `doc.json` 结尾且 `ADMIN_API_PATH != /admin` 时拦截并返回改写后的 JSON。
- 注解仍写死 `@Router /api/v1/admin/...`，避免全量改注释；运行时与真实路由对齐。
- 匹配规则：精确 `/api/v1/admin` 或前缀 `/api/v1/admin/`，避免误伤 `administrator` 类路径。

## 规范

- 注入上下文的键名全局统一。
- 管理端高危能力（debug）在控制器层再用 `IsAdminDebugOpsEnabled()` 二次拦截。
- 新增中间件时在 `routes.go` 明确挂载顺序。
