# backend/pkg/payment 留档

> 路径：`backend/pkg/payment/留档.md`  
> **最后更新**：2026-08-09

## 职责

多通道支付基础设施包，参考 go-wind-admin 的 `pkg/payment` 设计：

- 定义统一 `Provider` 接口：`CreatePay / VerifyNotify / QueryOrder / Refund / ValidatePayType / TestConnection`
- 可选接口 `PayloadVerifier`：供需要 `raw body + headers` 验签的通道（WeChat V3 / Stripe / PayPal）
- 归一化回调数据 `NotifyPayload`：验签后统一返回 `OutTradeNo / TradeNo / TradeStatus / Money / PayType`
- 提供全局通道注册表 `RegisterChannel / GetProvider / ListChannelMetas`
- 提供通道元数据 `ChannelMeta / ChannelVersionMeta / ConfigField`，供管理端动态渲染表单
- 提供通用工具：
  - `ParseExtConfig / MarshalExtConfig`：JSON 扩展配置解析
  - `ParseMoneyMinor / FormatMoneyYuan`：金额「分」与「元」互转
  - `NormalizeTradeStatus / NormalizeTradeNo`：状态/交易号规范化
  - `SignWithMD5 / RSASign / RSAVerify`：MD5 / RSA 签名基础
  - `HMACWithSHA256 / VerifyHMACWithSHA256`：HMAC-SHA256 签名（微信支付等）

## 设计要点

- `ext_config` 明文存储、明文回显，禁止脱敏/掩码/合并旧密钥
- 签名算法按 `sign_type` 分发，支持 `MD5` 与 `SHA256WithRSA`
- 通道实现通过 `init()` 自注册，如 `backend/app/plugins/pay_balance/epay`
- 与 `services.PaymentChannel` 旧接口并存，`payment_service.go` 优先用新 `Provider`，未注册时回退旧接口
