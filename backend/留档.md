# Backend 目录留档

> 路径：`backend/留档.md`  
> **最后更新**：2026-07-23

## 当前架构要点

- 数据访问：**GORM**（`pkg/db.DB`）；SQLite=`glebarez/sqlite`；换库只改 `DB_DRIVER` + DSN
- 建表编排：仅 `internal/migrate.RunAutoMigrate` → `models.AllGormModels()` + 种子/补丁
- 软删三套：`delete_time` / `is_deleted` / `announcements.deleted_at`（不用默认 `gorm.DeletedAt`）
- 分层：`controllers → services → models`；响应统一 `utils.Success` / `utils.Fail`

## 目录索引

| 路径 | 说明 |
|------|------|
| `app/` | 业务 MVC + 插件 |
| `internal/` | appinit / migrate / task |
| `pkg/` | config / db / middleware / presence / pluginregistry |
| `routes/` | 路由汇总 |
| `utils/` | 响应、JWT、邮件、掩码等 |

更细的说明见各子目录留档与 `doc/`。历史 changelog 已收敛，细节以代码与 `CLAUDE.md` 为准。

## 测试

```bash
go test ./backend/... -count=1
# Postgres 真机（可选）：FST_PG_DSN=... go test -tags integration ./backend/pkg/db/ -run Postgres -count=1
```

`pkg/db` 测试职责：索引/表探测、跨包锁行与聚合冒烟、Postgres integration；业务 CRUD 在 `app/models` / `app/services`。
