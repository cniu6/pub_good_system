# Backend 目录留档

> 路径：`backend/留档.md`  
> **最后更新**：2026-07-24

## 当前架构要点

- 数据访问：**GORM**（`pkg/db.DB`）；SQLite=`glebarez/sqlite`；换库只改 `DB_DRIVER` + DSN
- 建表编排：仅 `internal/migrate.RunAutoMigrate` → `models.AllGormModels()` + 种子/补丁
- 软删三套：`delete_time` / `is_deleted` / `announcements.deleted_at`（不用默认 `gorm.DeletedAt`）
- 分层：`controllers → services → models`；响应统一 `utils.Success` / `utils.Fail`

## 鉴权两套（别混）：JWT 登录 vs API Key 调用

| | JWT（登录会话） | API Key（程序调用） |
|--|--|--|
| **干什么用** | 人在浏览器里登录：密码/验证码登录后拿 access + refresh | 脚本/第三方直调业务 API，**不是登录** |
| **怎么带** | `Authorization: Bearer <jwt>` | `X-Api-Key: <明文key>`（见 `pkg/middleware/auth.go`） |
| **落库** | 会话表只存 **token 哈希**（`user_sessions`），不存 JWT 明文 | `users.apikey` 存 **明文** + `apikey_hint` 末 4 位；管理端掩码、用户中心可回显 |
| **隔离** | 必有 `token_type`（access/refresh）+ `auth_guard`（user/admin）；管理员/用户会话互不挤占 | 可配过期、IP 白名单、scope；**禁止**打登录类接口；**禁止**管理端写接口 |

## 必要 vs 不必要（总清单，改代码前先对）

> 目的：分清「设计如此勿乱砍 / 该留的运维能力」和「已删鸡肋 / 可选开关 / 勿当 Bug 乱修」。

### ✅ 必要（设计如此或已定为正式能力，勿当 Bug「修掉」）

| 项 | 说明 |
|--|--|
| JWT 强制 `token_type` + `auth_guard` | 防 access/refresh 混用、user/admin 串端；旧无字段 JWT 失效需重登 |
| Refresh **单次轮换** + 重放吊销同 guard 全部会话 | 防令牌被偷抢刷新；多设备正常各自会话互不影响；**同浏览器多标签并发**靠前端锁+BroadcastChannel 消误伤 |
| `cleanup_sessions_codes`（约 600s） | 清过期验证码 + 失效/过期会话行；**不替代**重放吊销，只是事后收尸 |
| API Key 明文落库 + 启动清理旧哈希 | `RepairHashedApiKeys`；旧 Key 重置属模型切换，与 JWT 无关 |
| 管理端 **DB 控制台**（`/admin/db/*`） | **正式管理能力**，不要用 `IsAdminDebugOpsEnabled` 关掉；只收紧只读 SQL |
| 管理端 **RBAC 角色权限矩阵** | 角色→权限码；路由 `meta.permission` 过滤菜单；海量用户不一人一配 |
| **用户等级** `user_level_caps` + `register_default_level` | 按 `users.level` 批量能力；自助注册默认等级后台可配，**默认 1** |
| 支付：永久查单失败落库停扫 | 「订单号不存在」等 → `payment_exceptions` + 订单 failed，不再扫 |
| `cleanup_expired_orders` | **保留**：只取消超时未支付，不查网关（与主动对账不是一回事） |
| Presence + `browser_id` 同浏览器收口会话 | 多标签不刷多行；选主用 BroadcastChannel，不按 token 分组 |

### ❌ 不必要（已移除 / 默认关 / 勿再加回当标配）

| 项 | 说明 |
|--|--|
| **TOTP**（登录二步 / 敏感操作 / 资料页） | 整包删除；不要再加回中间件/前端 composable |
| **导入导出**管理页与 API | 已删；运维改走 DB 控制台 / 备份下载 |
| **`reconcile_payment_orders` 自动任务默认开** | 种子与启动补丁强制 **Enabled=false**；handler 保留供手工点跑；用户端靠手动刷新，无前端 5s 轮询 |
| 调试 **WebSocket 终端** | 仅 `IsAdminDebugOpsEnabled` + 超管；生产默认关，不是标配运维入口 |
| GitHub Actions / CI 工作流 | 仓库不维护 `.github/workflows`；未明确要求勿擅自加 |

### ⏸️ 边界（未证实前别当必修 Bug）

- 支付对账「永久失败」子串启发式、`trade_no` 截断等业务边界  
- 重放检测「全量吊销同 guard」偏严：多标签误伤靠前端消；真·多设备互踢只发生在某一端触发重放之后（安全取舍）

### 真 Bug / 待修（与「不必要」无关）

| 项 | 说明 | 状态（2026-07-24） |
|--|--|--|
| API 访问日志明文落库（含 Cookie/token） | 产品故意：便于排查，不做日志脱敏 | **按设计保留** |
| `/ready`、`/metrics` | 已按产品要求删除（仅保留 `/health`） | **已删** |
| API 访问日志 MySQL 死锁丢记录 | 瞬时锁冲突无重试 | **已修**：可重试错误退避 |
| DB 控制台「只读」可被 `WITH` CTE 写库 | 首关键字误判 | **已修**：只读仅 SELECT/SHOW/EXPLAIN |
