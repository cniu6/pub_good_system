## 最近更新（2026-07-17）

- 正式启动：`internal/appinit` + `internal/migrate` + `internal/task`；`cmd/server` 仅薄壳。
- 数据库自迁移收拢到 `internal/migrate/auto_migrate.go`（含 `auto_job_*` 表）。
- **自动任务管理器**：核心在 `internal/task`（SQL 定义/执行记录/内存缓存/调度）；管理 API `/api/v1/{ADMIN}/auto-jobs/*`。
- 路由拆分：`routes/public.go` `user.go` `admin.go`。
- 运维脚本在根目录 `tools/`；单元测试仍在各包旁的 `*_test.go`（Go 要求），说明见 `backend/tests/README.md`。

## 目录结构（当前）

```text
backend/
├── app/                 # 业务：controllers / models / services / plugins
├── routes/              # SetupRoutes + public/user/admin
├── pkg/                 # 零件：config / db连接 / middleware / pluginregistry
├── internal/
│   ├── appinit/         # 启动编排
│   ├── migrate/         # 全部自迁移（含自动任务表）
│   └── task/            # 自动任务核心（原 autojob）
├── cmd/server/          # 进程薄壳 + 前端托管
├── utils/ · docs/
├── tests/README.md      # 测试放置说明（单元测试不挪包外）
└── 留档.md
```

`pkg` = 零件；`internal` = 开机骨架（启动 / 建表 / 任务调度）。业务 API 不进 `internal`。

## 自动任务（记录）

| 项 | 说明 |
|----|------|
| 表 | `auto_job_definitions`、`auto_job_runs` |
| 包 | `backend/internal/task` |
| 启动 | `services.StartBackgroundTasks()` → `task.Start()`；空表自动导入默认任务 |
| 内存 | 启动 `ReloadCache()`；调度 tick 读内存，改配置/启停后刷新 |
| API | `app/controllers/admin/auto_job_controller.go` |
| 默认任务 | 验证码会话清理、过期支付单、幂等键、记录修剪、卡住巡检 |
| 记录策略 | 调度空跑不落库；失败/手动照常记；详 [internal/task/留档.md](./internal/task/留档.md) |
| 单测 | `go test ./backend/internal/task/ -count=1` |

旧 `app/services/autojob`、`internal/task/manager.go` / `store.go` 已删除；现为 `config`/`definition`/`run`/`stuck`/`overview`/`runtime`，勿再引用旧名。
