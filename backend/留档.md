## 最近更新（2026-07-20）

- **根目录唯一 `.env`**：`findDotEnvPath` = exe 同级 → `../.env` → cwd 向上；跳过 `frontend` 纯 VITE 与 `backend/.env`（已废弃）。
- **Presence / 在线用户**：`pkg/presence` + `routes/ws.go`；管理 API `/online/*`；前端心跳与在线列表。
- **会话强退**：`POST /public/session/force-logout`（过期 token 可吊销）；JWT 增加 ignore-expiry 解析。
- **手机国际区号 / geo**：`utils/phone.go`、`dial_codes.go`；公开 geo 接口。
- **邮件出站代理**：`utils/proxy_*.go`；SMTP TLS 回退；设置页邮件/短信 Tab 增强。
- **短信模板 CRUD**：`sms_template` 模型 + 管理控制器；日志聚合查询增强。
- **SQLite**：方言 `DATE_FORMAT` 嵌套回退修复；临时库测试路径注释对齐根 `.env`。

## 目录结构（当前）

```text
backend/
├── app/                 # 业务：controllers / models / services / plugins
├── routes/              # SetupRoutes + public/user/admin/ws
├── pkg/                 # config / db / middleware / presence / pluginregistry
├── internal/
│   ├── appinit/         # 启动编排
│   ├── migrate/         # 全部自迁移（含自动任务表）
│   └── task/            # 自动任务核心
├── cmd/server/          # 进程薄壳 + 前端托管
├── utils/ · docs/
├── tests/README.md
└── 留档.md
```

`pkg` = 零件；`internal` = 开机骨架。业务 API 不进 `internal`。

## 启动

```bash
# 必须在仓库根目录（读根 .env）
go run .
./dev.bat
```

配置：只维护根目录 `.env`（参考 `.env.example`）。打包后把 `.env` 放 **exe 同级**或 **上级**。密钥勿提交。  
更多：`pkg/config/全局配置管理与环境加载.md` · `doc/配置系统.md` · `doc/在线会话与Presence.md`。
