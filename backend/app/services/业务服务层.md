# 业务服务层 (Services)

> 路径：`backend/app/services/`  
> **最后更新**：2026-07-18

## 简介

控制器与模型之间的业务逻辑层：认证、设置、支付、网关、提现、实名、短信、邮件等。

**后台周期任务不在本层实现调度**：统一由 [`backend/internal/task`](../../internal/task)（SQL 定义 + 内存调度 + 执行记录）。  
本目录仅保留：

- `background_tasks.go`：`StartBackgroundTasks()` 注入配置刷新回调后启动 `task.Start`

清理任务状态查询已内联在 `backend/app/controllers/system_controller.go`（`GetCleanupStatus`），不再经由本层。

## 文件一览

| 文件 | 职责 |
|------|------|
| `auth_service.go` | 登录注册、会话、Token |
| `user_service.go` | 用户资料与管理侧用户操作 |
| `user_money_score_service.go` | 余额/积分变更与日志 |
| `settings_service.go` | 系统设置缓存、公开 app-config |
| `payment_service.go` | 支付下单、回调、订单与网关绑定校验 |
| `payment_channel.go` | 通用支付通道接口与注册表（实现在 plugins/pay_balance） |
| `pay_gateway_service.go` | 支付通道 CRUD |
| `withdraw_service.go` | 提现审核/打款 |
| `realname_service.go` | 实名审核 |
| `email_service.go` / `sms_service.go` | 邮件/短信 |
| `background_tasks.go` | 启动 `internal/task` |

## 公开 app-config

`SettingsService.GetPublicAppConfig()` → `GET /api/v1/public/app-config`

## 支付回调绑定校验

`validatePaymentNotifyBinding`：网关 / 通道 / 类型一致才可入账；日志脱敏。

## 测试

单元测试 `*_test.go` 与本包同目录（Go 规范）。运维/集成脚本见项目根 `tools/`。

```bash
go test ./backend/app/services/ -count=1
```
