# 业务服务层 (Services)

> 路径：`backend/app/services/`  
> **最后更新**：2026-07-16

## 简介

控制器与模型之间的业务逻辑层：认证、设置、支付、网关、提现、实名、短信、邮件、清理任务等。

## 文件一览

| 文件 | 职责 |
|------|------|
| `auth_service.go` | 登录注册、会话、Token 相关业务 |
| `user_service.go` | 用户资料与管理侧用户操作 |
| `user_money_score_service.go` | 余额/积分变更与日志 |
| `settings_service.go` | 系统设置缓存、公开 app-config、`ApplyGlobalRuntimeConfig` |
| `payment_service.go` | 支付下单、回调处理、**订单与网关绑定校验** |
| `epay_service.go` | 易支付签名/请求 |
| `pay_gateway_service.go` | 支付通道 CRUD |
| `withdraw_service.go` | 提现审核/打款 |
| `realname_service.go` | 实名审核 |
| `email_service.go` / `sms_service.go` | 邮件/短信发送 |
| `cleanup_service.go` / `background_tasks.go` | 清理与后台任务 |

## 公开 app-config（前端依赖）

`SettingsService.GetPublicAppConfig()` → `PublicAppConfig`，其中：

- `admin_api_path`：来自 `config.NormalizeAdminAPIPath(AdminAPIPath)`
- 站点名、极验、实名/提现开关等

接口：`GET /api/v1/public/app-config`（`public/settings_controller.go`）

## 支付回调绑定校验（安全）

`validatePaymentNotifyBinding` 至少校验：

- 订单 `GatewayID` 与回调网关一致  
- `PaymentChannel` / `PaymentType` 与网关配置一致  
- 标准回调类型与订单类型一致（易支付非标准 type 有白名单宽松逻辑）

失败不得入账。回调日志走脱敏，避免 sign/完整 pid 等明文刷屏。

## 运行时配置

`ApplyGlobalRuntimeConfig`：Clone 全局配置 → 写字段 → `UpdateGlobalConfig`，避免并发写竞态。
