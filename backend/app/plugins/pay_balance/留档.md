# pay_balance 插件留档

> 路径：`backend/app/plugins/pay_balance/留档.md`  
> **最后更新**：2026-08-09

## 职责

余额充值支付通道插件。通过 `plugin.go` 在 `Init()` 时注册旧 `services.PaymentChannel`，同时 `blank import` 同级目录下的 Provider 包完成 `pkg/payment` 新接口注册。

## 目录

| 包 | 说明 |
|----|------|
| `epay/` | 易支付：V1 MD5（mapi.php / submit.php）、V2 RSA（/api/pay/create/query/refund），支持创建/查单/回调/退款 |
| `wechat/` | 微信支付模板：V2 MD5/HMAC-SHA256、V3 RSA（/v3/refund/domestic/refunds 退款、/v3/certificates 测连） |
| `alipay/` | 支付宝模板：V2 RSA2，支持电脑/手机网站支付、回调验签、`alipay.trade.refund` 退款 |
| `paypal/` | PayPal：OAuth2 + Orders v2，回调官方验证、capture 退款 |
| `stripe/` | Stripe：PaymentIntents + Webhook HMAC-SHA256 验签、`/v1/refunds` 退款 |
| `plugin.go` | 插件入口，blank import 触发各 Provider `init()` 自注册 |

## 新增通道

1. 在 `backend/app/plugins/pay_balance/<channel>/` 下实现 `pkg/payment.Provider`。
2. `init()` 中调用 `payment.RegisterChannel(meta, NewProvider)`，填写 `ChannelMeta.Versions[].ConfigFields`。
3. 在 `plugin.go` 增加 `_ "fst/backend/app/plugins/pay_balance/<channel>"`。
4. 多个密钥/API Key/SHA256 等统一放在 `ext_config` JSON 中，明文落库、明文回显。
