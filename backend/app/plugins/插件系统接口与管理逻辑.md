# 插件系统接口与管理逻辑 (Plugins)

## 简介

提供系统的可扩展性，支持通过 `pluginregistry` + `Manager` 装载业务插件。

## 核心 API

| 符号 | 文件 | 说明 |
|------|------|------|
| `Plugin` / `BasePlugin` | `interface.go` | 插件接口与默认实现 |
| `Manager` / `NewManager` | `manager.go` | 注册、依赖解析、LoadAll / RegisterAllRoutes / ShutdownAll |
| `AutoRegisterAll` | `global_registry.go` | 将 `pluginregistry` 中已注册插件装入 Manager |

启动流程见 `backend/internal/appinit/start.go`：

```go
pluginMgr := plugins.NewManager()
plugins.AutoRegisterAll(pluginMgr)
_ = pluginMgr.LoadAll()
pluginMgr.RegisterAllRoutes(apiGroup)
```

各插件在 `init()` 中调用 `pluginregistry.Register(NewPlugin())`；根入口 `main.go` 通过 blank import 触发 init。

## 规范

- 插件应具备独立的路由前缀。
- 初始化失败不应影响主程序启动（Manager 会记录错误并跳过该插件路由）。
