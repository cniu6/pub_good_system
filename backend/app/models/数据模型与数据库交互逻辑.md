# 数据模型与数据库交互

> 路径：`backend/app/models/`  
> **最后更新**：2026-10-29

- 访问层：GORM（`backend/pkg/db`）
- 模型：`backend/app/models/*.go`（gorm tag + snake_case）
- 迁移：`internal/migrate.RunAutoMigrate` + `AllGormModels()`
- 约定与示例：见 [`doc/数据库模型.md`](../../../doc/数据库模型.md)

命名：表/字段一律小写+下划线；禁止业务里写死 CamelCase 列名。

## 跨库长文本

`LongText`（`long_text.go`）按驱动给类型：PostgreSQL 用 `text`，MySQL 与 SQLite 用 `mediumtext`。
SQLite 继续用 `mediumtext`，是为了避免 AutoMigrate 把已有开发库的列重建。
日志/公告的 `request_body`、`response_body`、`content` 都用它。

## 查询构造收口

同一类筛选只保留一个构造函数：在线会话 `onlineSessionsQuery`、公告可见性 `visibleAnnouncementsQuery`、
支付通道配置 `PayGateway.ExtConfigMap()`。新增查询先复用，不要再拼一份 SQL。

## 存量修复

`RepairVerificationCodeTable` / `RepairHashedApiKeys` 由 `RunAutoMigrate` 调用，只在旧库首次启动时生效，
属正式启动链路，不要当死代码删除。

## 返回消息

自 2026-08-09，模型层 `errors.New` / `fmt.Errorf` 的中文错误 message 已统一改为英文（如 `Invalid order status transition: %d -> %d`、`Invalid user balance` 等），供 services/controllers 直接透传给前端。
