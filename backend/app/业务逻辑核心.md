# 业务逻辑核心 (App)

> 路径：`backend/app/`  
> **最后更新**：2026-08-10

## 简介

后端业务核心：请求处理、数据持久化、服务编排、插件扩展。数据库标识统一 **小写 + 下划线**。

**鉴权别混**：登录用 JWT（`utils/jwt` + 会话表）；程序调用用 API Key（`users.apikey` 明文）。  
**必要 / 不必要总清单**（TOTP/导入导出已删、对账默关、RBAC/等级/DB 控制台等）见 [backend/留档.md](../留档.md)。

## 分层调用

```text
HTTP → controllers → services → models → DB
                  ↘ utils / pkg/config
```

- 控制器：参数绑定、权限上下文、响应封装。  
- 服务：事务边界、跨模型规则（支付绑定、提现状态机等）。  
- 模型：GORM 字段映射与查询，禁止业务里写死 CamelCase 列名。

## 近期业务要点

### 2026-08

1. **管理端汇率/货币配置（2026-08-10）**：`controllers/admin/payment/payment_controller.go` 新增 `/currency/config`（GET/PUT）、`PUT /currency/rates/:id`、`POST /currency/rates/:id/refresh` 与 `POST /currency/rates/batch-refresh` 系列；`ExchangeRate` 新增 `fixed_amount` 字段支持固定加额/差价；新增单条/批量汇率从上游 API 刷新并保留原 `rate_type` 与 `fixed_amount`；自动任务新增 `refresh_exchange_rates` 每日定时刷新动态汇率；修复 `SetSystemSetting` 的 `sql.ErrNoRows` 处理；启动时 `SeedExchangeRates()` 自动插入内置常用汇率。详见 [`doc/支付订单系统.md`](../../doc/支付订单系统.md)。
2. **控制器目录重构**：`controllers/{scope}/{business}/controller.go` 二级结构，包名英文，`@Tags` 中文；相同业务跨 scope 同名包由 routes import alias 区分。详见 [doc/API路由.md](../../doc/API路由.md)。
2. **返回消息英文化**：`controllers` / `services` / `models` / `middleware` / `utils` / `plugins` / `internal/task` 中所有 `utils.Fail` / `utils.SuccessMsg` / `Success(c, gin.H{"message": ...})` / `errors.New` / `fmt.Errorf` 的中文 message 统一改为英文；注释、日志、Swagger 描述保持中文。
3. **Scalar 分组**：按 `v1------Admin` / `v1------User` / `v1------Public` / `v1------System` 等 `x-tagGroups` 做视觉层级；路径自动推断 tag 兜底。
