# 业务逻辑核心 (App)

> 路径：`backend/app/`  
> **最后更新**：2026-07-16

## 简介

后端业务核心：请求处理、数据持久化、服务编排、插件扩展。数据库标识统一 **小写 + 下划线**。

## 目录

| 子目录 | 说明 | 留档 |
|--------|------|------|
| `controllers/` | public / user / admin 控制器 | [用户认证与请求处理控制器.md](./controllers/用户认证与请求处理控制器.md) |
| `models/` | GORM 模型与数据访问 | [数据模型与数据库交互逻辑.md](./models/数据模型与数据库交互逻辑.md) |
| `services/` | 业务服务层 | [业务服务层.md](./services/业务服务层.md) |
| `plugins/` | 插件实现 | [插件系统接口与管理逻辑.md](./plugins/插件系统接口与管理逻辑.md) |
| `sms/` | 短信厂商实现细节 | 见 `services/sms_service.go` 与 doc/短信插件系统 |

## 分层调用

```text
HTTP → controllers → services → models → DB
                  ↘ utils / pkg/config
```

- 控制器：参数绑定、权限上下文、响应封装。  
- 服务：事务边界、跨模型规则（支付绑定、提现状态机等）。  
- 模型：GORM 字段映射与查询，禁止业务里写死 CamelCase 列名。

## 近期业务要点（2026-07）

1. **支付回调**：服务层校验网关 ID/渠道/类型与订单绑定；日志脱敏。  
2. **公开配置**：`GetPublicAppConfig` 下发 `admin_api_path` 等。  
3. **代登录**：生产禁用；禁止代登管理员；短 TTL + 审计日志。  
4. **运行时配置**：`ApplyGlobalRuntimeConfig` 使用 config 包并发安全更新。

## 注意事项

- 模型/表结构变更须同步 `models` 留档与 `doc/数据库模型.md`。  
- 新增管理端接口时：路由挂在 `ADMIN_API_PATH` 分组；Swagger 注解仍可写 `/api/v1/admin/...`（运行时改写）。
