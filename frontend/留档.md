## 必要 vs 不必要（总清单）

> 与后端对照见 [`../backend/留档.md`](../backend/留档.md)。改 UI/鉴权前先对这张表。

### ✅ 必要

| 项 | 说明 |
|--|--|
| Token 自动刷新 | `VITE_AUTO_REFRESH_TOKEN=Y`；`setupAutoRefresh` + 401 走 `handleRefreshToken` |
| 跨标签 refresh 协调 | `service/http/token-refresh.ts`：锁互斥 + BroadcastChannel 同步；防多标签抢同一枚 refresh 触发后端全家踢 |
| `authGeneration` | 登出/登录递增；丢弃过期静默刷新，避免会话「复活」 |
| Presence 多标签选主 | `usePresence` + BroadcastChannel；仅 leader 建 WS；login-as 与管理员本人独立选主 |
| 管理端 RBAC | 路由 `meta.permission`；侧栏按 `permission_codes` 过滤；角色矩阵页 |
| 用户等级能力 | 充值/提现/API Key 受等级限制；注册默认等级 `register_default_level`（默认 1） |
| 侧边栏宽度 | 拖拽右边缘调宽；**重置在系统设置抽屉**（`SettingDrawer`），侧栏不挂浮钮 |
| 改 frontend 后 `pnpm lint` | 硬规则；本地能 dev ≠ 通过 |
| 管理端 i18n | zh_CN + en_US 成对；见 `.cursor/rules/admin-i18n-required.mdc` |

### ❌ 不必要（已移除 / 勿加回）

| 项 | 说明 |
|--|--|
| TOTP 登录二步 / `useSensitiveTotp` | 整包删除 |
| 导入导出页 / `import-export` API | 已删 |
| 充值页订单 **5s 自动轮询** | 已删；保留手动「刷新状态」 |
| 侧栏底部「重置宽度」浮钮 | 已挪进系统设置抽屉 |

### 可选 / 环境

| 项 | 说明 |
|--|--|
| `VITE_TOKEN_REFRESH_AHEAD` | 到期前提前刷新秒数，默认 60 |
| 服务器管理「调试/终端」Tab | 依赖后端 debug ops；生产可无入口 |

## 最近更新（摘要）

- **支付通道管理端表单自适应（2026-08-09）**：`src/views/admin/pay-gateways/index.vue` 改为从 `/payment/channels/metas` 拉取已注册通道元数据，根据通道类型/版本/签名算法动态渲染配置字段；新增 `ext_config` JSON 编辑器、版本、签名算法、设备、币种、过期时间、主动查单开关/冷却/批次等字段；支付密钥/扩展配置明文展示、明文回传。
- **后端返回消息英文化（2026-08-09）**：所有接口的 `message` 字段统一改为英文（`utils.Fail` / `utils.SuccessMsg` / `Success` / `errors.New` / `fmt.Errorf`）。前端展示报错/成功提示时直接使用 `message`，或按 `code` 映射到本地化文案；不要把英文 message 硬编码为中文。
- **数据库控制台（2026-07-24）**：服务器管理内改为左侧对象树、右侧数据/结构/SQL/DDL 分区；结构页展示字段、注释、索引/联合索引和外键。生产固定只读，非生产是否开放受控行级写入由后端 `ENABLE_ADMIN_DB_WRITE` 决定。
- **Token / 会话（2026-07-24）**：自动刷新；跨标签锁与同步；失效后登录弹窗路径以当前代码为准；Presence 30s + 选主；用户端 localStorage 同步、管理端 sessionStorage 隔离。
- **系统设置抽屉**：侧边栏宽度滑条旁「重置宽度」（默认 240）。
- **基础设置**：`register_default_level`（注册默认等级，默认 1）。
- **历史**：站内公告、短信、finance API、PhoneInput、Iconify 离线、两套管理路径等见源码与 `doc/`。

## 环境变量约定

| 文件 | 用途 |
|------|------|
| `.env` | 公共默认（名称、路由、Token、语言等） |
| `.env.dev` | `pnpm dev`（`--mode dev`）覆盖：代理、本地 API |
| `.env.production` | 生产/embedded 同源等 |
| `.env.example` | 示例，可提交 |

与后端根 `.env` **分开维护**；仅需人工对齐 `VITE_ADMIN_BASE_PATH` ↔ `ADMIN_PATH`。

常用键：`VITE_DEFAULT_LANG=zhCN`、`VITE_API_URL`、`VITE_ADMIN_BASE_PATH`、`VITE_AUTO_REFRESH_TOKEN`。

## 📂 目录结构（精简）

```text
frontend/
├── src/
│   ├── components/common/     # PhoneInput、NovaIcon 等
│   ├── composables/           # usePresence
│   ├── modules/               # iconify-offline、i18n 等
│   ├── views/admin/           # 仪表盘/用户/在线/日志/设置…
│   ├── views/user/            # 用户端
│   ├── router/                # admin.routes / routes.static / guard
│   ├── store/                 # auth / settings / app
│   └── service/api/           # admin|user|geo|session|app-config
├── locales/                   # zh_CN / en_US
├── .env / .env.dev / .env.production / .env.example
└── vite.config.ts
```

## 两套管理路径

| 配置 | 含义 | 默认 |
|------|------|------|
| `VITE_ADMIN_BASE_PATH` | 管理**页面**入口 | `/system-mgr` |
| 运行时 `admin_api_path` | 管理 **REST** 前缀 | `/admin` → `/api/v1/admin` |
| `VITE_ADMIN_API_PATH` | 仅回退 | `/admin` |

```bash
pnpm lint
```
