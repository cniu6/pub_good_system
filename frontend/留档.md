## 最近更新（2026-07-16）

- **管理端 API 运行时注入**：启动时 `fetchAppConfig` → `admin_api_path` → `setRuntimeAdminApiPath`；`getAdminApiBase()` 拼 `/api/v1{前缀}`。
- 管理端 API 模块改为请求时 `baseUrl()`，避免 import 时写死路径。
- `VITE_ADMIN_API_PATH` 仅作 app-config 失败回退；正常以后端 `ADMIN_API_PATH` 为准。
- 页面入口仍用 `VITE_ADMIN_BASE_PATH`（默认 `/system-mgr`），与 API 前缀分离。
- 管理端 token 统一 `authStorage`；设置页不再混用 `local.get('accessToken')`。
- `env.d.ts` 补充 `VITE_ADMIN_BASE_PATH` / `VITE_ADMIN_API_PATH` / `VITE_BUILD_MODE`。
- **【已删除】前端模板 Demo**：`src/views/demo/**`、`service/api/demo.ts`、`list.ts`、用户侧栏「关于」(`/user/about` → 原 demo about)。i18n 里若仍有 `demo.*` 文案键可忽略。

### 更早（2026-02-24）

- 管理端侧边栏移除独立“调试”入口；系统监控内存/磁盘/网络卡片调整。

## 📚 核心模块

### 1. 请求系统

**关键文件**:
- `src/service/http/` - Alova 请求封装
- `src/service/api/user/` - 用户 API（登录、个人中心）
- `src/service/api/admin/` - 管理端 API（`base.ts` 运行时 base）
- `src/service/api/app-config.ts` - 公开配置（含 `admin_api_path`）
- `src/store/settings.ts` - 加载配置并注入管理 API 前缀

**管理端请求示例**:
```typescript
import { getAdminApiBase, adminApiUrl } from '@/service/api/admin/base'

// 完整 base，如 /api/v1/admin 或 /api/v1/mgr-api
const base = getAdminApiBase()
// 子路径
const url = adminApiUrl('/users')
```

📖 **详细文档**: [src/service/网络请求与API定义.md](src/service/网络请求与API定义.md) · [../doc/前端请求.md](../doc/前端请求.md)

### 1.1 两套管理路径

| 配置 | 含义 | 默认 |
|------|------|------|
| `VITE_ADMIN_BASE_PATH` | 管理**页面**入口 | `/system-mgr` |
| 运行时 `admin_api_path` | 管理 **REST** 前缀 | `/admin` → `/api/v1/admin` |
| `VITE_ADMIN_API_PATH` | 仅回退 | `/admin` |

### 2. 路由系统

**关键文件**:
- `src/router/index.ts` - 路由配置

**使用方式**:
```typescript
import { useRouter } from 'vue-router'

const router = useRouter()

// 跳转
router.push('/dashboard')

// 获取参数
const id = router.currentRoute.value.params.id
```

### 3. 状态管理

**关键文件**:
- `src/store/auth.ts` - 认证状态

**使用方式**:
```typescript
import { useAuthStore } from '@/store'

const authStore = useAuthStore()

// 登录
await authStore.login({ username, password })

// 获取用户信息
console.log(authStore.userInfo)

// 登出
authStore.logout()
```

### 4. 国际化

**关键文件**:
- `src/locales/*.json` - 语言文件

**使用方式**:
```vue
<template>
  <div>{{ $t('login.title') }}</div>
</template>

<script setup>
import { useI18n } from 'vue-i18n'

const { t } = useI18n()

console.log(t('login.title'))
</script>
```

### 5. 类型定义

**关键文件**:
- `src/typings/entities/*.d.ts` - 实体类型

**使用方式**:
```typescript
// 使用预定义类型
const user = ref<Entity.User | null>(null)

// 扩展类型
declare namespace Entity {
  interface NewEntity {
    id: number
    name: string
  }
}
```

## 📝 开发规范

### 1. 组件命名

```vue
<!-- ✅ 推荐 -->
<UserProfile />
<UserList />

<!-- ❌ 不推荐 -->
<user-profile />
<userprofile />
```

### 2. API 命名

```typescript
// ✅ 推荐
fetchGetUserList
fetchCreateUser
fetchUpdateUser

// ❌ 不推荐
getUserList
getUser
requestUserList
```

### 3. 类型命名

```typescript
// ✅ 推荐
interface UserInfo { }
type UserRole = 'admin' | 'user'

// ❌ 不推荐
interface userInfo { }
type userrole = string
```

## ⚠️ 开发注意事项

1. **使用别名**: 使用 `@/` 别名导入模块
2. **类型安全**: 为所有变量和函数添加类型
3. **错误处理**: 使用 try-catch 处理异步操作
4. **组件拆分**: 大组件拆分为小组件
5. **代码复用**: 使用 composables 复用逻辑
