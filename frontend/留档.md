## 环境变量约定

| 文件 | 用途 |
|------|------|
| `.env` | 公共默认（名称、路由、Token、语言等） |
| `.env.dev` | `pnpm dev`（`--mode dev`）覆盖：代理、本地 API |
| `.env.production` | 生产/embedded 同源等 |
| `.env.example` | 示例，可提交 |

与后端根 `.env` **分开维护**；仅需人工对齐 `VITE_ADMIN_BASE_PATH` ↔ `ADMIN_PATH`。

## 📂 目录结构（精简）

```text
frontend/
├── src/
│   ├── components/common/     # PhoneInput、NovaIcon 等
│   ├── composables/           # usePresence
│   ├── modules/               # iconify-offline、i18n 等
│   ├── views/admin/           # 仪表盘/用户/在线/日志/设置/模板…
│   ├── views/user/            # 用户端
│   ├── router/                # admin.routes / routes.static / guard
│   ├── store/                 # auth / settings / app
│   └── service/api/           # admin|user|geo|session|app-config
├── locales/                   # zh_CN / en_US
├── .env / .env.dev / .env.production / .env.example
└── vite.config.ts
```

---

## 两套管理路径

| 配置 | 含义 | 默认 |
|------|------|------|
| `VITE_ADMIN_BASE_PATH` | 管理**页面**入口 | `/system-mgr` |
| 运行时 `admin_api_path` | 管理 **REST** 前缀 | `/admin` → `/api/v1/admin` |
| `VITE_ADMIN_API_PATH` | 仅回退 | `/admin` |

## 开发

```bash
cd frontend && pnpm install && pnpm dev
```

管理端新增文案必须同步 `locales/zh_CN.json` + `en_US.json`。
