## 启动顺序（务必遵守）

```text
createApp
  → installPinia
  → settingsStore.loadConfig()   // 注入 admin_api_path
  → i18n / installRouter(mode)
  → directives / assets
  → mount
```

- **admin 模式**：`authStorage.enableSessionIsolation()`
- **页面入口**：`VITE_ADMIN_BASE_PATH`
- **REST 前缀**：运行时 `admin_api_path`，见 service/admin/base.ts

## 注意事项

- 符合项目 ESLint；逻辑与样式尽量分离。
- 管理端 API 禁止写死 `/api/v1/admin`。
- 相对路径留档链接优先用仓库相对路径，避免本机绝对路径失效。
