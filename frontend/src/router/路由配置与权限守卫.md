# 路由配置与权限守卫 (Router)

> 路径：`frontend/src/router/`  
> **最后更新**：2026-07-16

## 简介

用户端 history + 管理端 hash 双模式；守卫负责 Token / 角色 / 管理端懒加载。

## 文件结构

```text
router/
├── index.ts            # 路由实例（user / admin 双模式）
├── constants.ts        # getAdminBasePath / buildAdminEntryUrl 等
├── guard.ts            # 全局守卫
├── routes.inner.ts     # 登录、错误页等固定路由
├── routes.static.ts    # 用户端静态业务路由
├── admin.routes.ts     # 管理端路由（独立 chunk）
├── admin.loader.ts     # 管理端动态加载
└── runtime-mode.ts     # 运行时 mode
```

## 页面入口路径

- `VITE_ADMIN_BASE_PATH`（默认 `/system-mgr`）= 后端 `ADMIN_PATH`。
- `getAdminBasePath()` / `buildAdminEntryUrl()` 用于从用户端跳管理端。
- **与** `ADMIN_API_PATH`（REST 前缀）**无关**。API 见 `service/api/admin/base.ts`。

## 规范

- 路由 `meta` 用于菜单与权限。
- 未授权重定向登录页。
- 管理端路由独立打包，普通用户不可见。
