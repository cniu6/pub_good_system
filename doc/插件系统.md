# 插件系统

> **关联代码**:
> - `backend/app/plugins/interface.go` — `Plugin` / `BasePlugin`
> - `backend/app/plugins/manager.go` — `Manager` / `NewManager`
> - `backend/app/plugins/global_registry.go` — `AutoRegisterAll`
> - `backend/pkg/pluginregistry` — 全局注册表
> - `backend/internal/appinit/start.go` — 启动时装载

更细的接口说明见：`backend/app/plugins/插件系统接口与管理逻辑.md`。

---

## 架构（简）

1. 插件包 `init()` → `pluginregistry.Register(NewPlugin())`
2. 根入口 blank import（`main.go` 的 `// @plugins-start` 区域）触发 init
3. 启动时：`NewManager()` → `AutoRegisterAll(mgr)` → `LoadAll()` → `RegisterAllRoutes`

```go
pluginMgr := plugins.NewManager()
plugins.AutoRegisterAll(pluginMgr)
if err := pluginMgr.LoadAll(); err != nil {
    log.Printf("[Plugin] 插件加载失败: %v", err)
}
pluginMgr.RegisterAllRoutes(apiGroup)
```

### 核心类型

| 符号 | 文件 | 说明 |
|------|------|------|
| `Plugin` | `interface.go` | 插件必须实现的接口 |
| `Manager` | `manager.go` | 插件管理器 |
| `NewManager` | `manager.go` | 创建管理器 |
| `AutoRegisterAll` | `global_registry.go` | 从 pluginregistry 装载到 Manager |

> 旧名 `PluginManager` / `NewPluginManager` / `GetPlugins` 已废弃，请使用上表。

## 新增插件（最短路径）

1. 在 `backend/app/plugins/<name>/` 实现 `Plugin`（可嵌入 `BasePlugin`）
2. `init()` 里 `pluginregistry.Register(NewPlugin())`
3. 在根目录 `main.go` 的 `@plugins-start` / `@plugins-end` 区域加 blank import  
   （开发时也可跑 `go run backend/app/plugins/gen_plugins.go` 自动扫描写入）

```go
// main.go
// @plugins-start
_ "fst/backend/app/plugins/pay_balance"
_ "fst/backend/app/plugins/sms"
// @plugins-end
```

demo 插件需编译标签：`-tags demo`（见 `main_demo_plugins.go`）。
