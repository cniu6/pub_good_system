## 配置说明

### 必需的环境变量

在 `.env` 文件中配置以下 SMTP 参数（**首次部署 / 库中为空时的兜底**）：

```env
# SMTP 服务器配置
SMTP_HOST=smtp.gmail.com          # SMTP服务器地址
SMTP_PORT=587                     # SMTP端口 (25/587/465)
SMTP_USERNAME=your-email@gmail.com # 登录用户名
SMTP_PASSWORD=your-app-password   # 登录密码/应用专用密码
SMTP_SSL_TYPE=ssl                 # ssl=隐式TLS(465)；587 请用非 ssl（走 STARTTLS）

# 发件人配置（可选）
SYSTEM_EMAIL_ADDRESS=noreply@yourapp.com  # 发件人邮箱
SYSTEM_EMAIL_NAME=YourAppName             # 发件人名称

# SMTP 出站代理（可选；国内直连 Yandex/Gmail 不通时开启）
SMTP_PROXY_ENABLED=false
SMTP_PROXY_TYPE=socks5            # http | https | socks5 | socks5h
SMTP_PROXY_HOST=
SMTP_PROXY_PORT=1080
SMTP_PROXY_USERNAME=
SMTP_PROXY_PASSWORD=
```

管理端「系统设置 → 邮件」保存后，对应写入 `system_settings`（key 见下节）。

### 配置加载

启动时 `.env` 载入 `config.GlobalConfig`；随后 `services.ApplyGlobalRuntimeConfig()` 用数据库覆盖非空项。

相关结构见 `backend/pkg/config/config.go`（含 `SMTPProxy*` 字段）。

## 配置优先级（必读）

> 留档日期：2026-07-19。改邮件/代理配置前先看这里，避免「改了 .env 不生效」。

### 结论（一句话）

**管理员后台 / `system_settings`（SQL）优先；`.env` 只做启动底稿与空值 fallback。**

### 合并规则

代码：`backend/app/services/settings_service.go` → `ApplyGlobalRuntimeConfig()`  
读库：`getRuntimeString` / `getRuntimeBool`（缓存或 DB）

| 情况 | 实际生效 |
|------|----------|
| 后台已保存过（库里有非空字符串 / 明确的 true\|false） | **用库里的** |
| 库里该 key 不存在，或字符串值为空 | 用 `.env` 启动时写入的底稿 |
| 只改 `.env`、不重启 | **不生效**（底稿只在进程启动时加载） |
| 后台保存后 | 一般会触发运行时合并，**立刻以库为准** |

布尔项（如 `smtp_proxy_enabled`、`smtp_ssl`）：库中为 `true`/`false`/`1`/`0` 时**一律以库为准**，不会被后来改的 `.env` 盖掉。

### 两边都改了怎么办

1. 先以前端「系统设置 → 邮件」里显示的为准（读的就是库）。  
2. 若要改 `.env` 并让它生效：要么把库里对应 key 清空/删掉再重启，要么直接在后台改并保存（推荐只认后台）。  
3. **日常建议只维护一处**：生产用管理后台；`.env` 仅首次安装默认值。

### 相关 `system_settings` key

| key | 说明 |
|-----|------|
| `smtp_host` / `smtp_port` / `smtp_username` / `smtp_password` / `smtp_ssl` | SMTP 本体 |
| `smtp_proxy_enabled` / `smtp_proxy_type` / `smtp_proxy_host` / `smtp_proxy_port` | 出站代理 |
| `smtp_proxy_username` / `smtp_proxy_password` | 代理账密（可选） |
| `system_email_address` / `system_email_name` | 发件显示 |

也可直接 SQL 更新上述 key，然后重启或再走一次后台保存以刷新运行时。

## SMTP 出站代理

国内直连部分国外 SMTP（如 Yandex）常失败时，打开代理开关。

- 通用拨号：`backend/utils/proxy_dialer.go`（SOCKS5 用官方 `golang.org/x/net/proxy`；HTTP/HTTPS CONNECT 自研，按标准响应解析，无额外长度截断）
- 邮件侧：`email.go` 在 plain / STARTTLS / 隐式 SSL 拨号时统一走 `DialViaProxy` / `DialTLSViaProxy`
- **开关关闭 = 完全直连**，其它代理字段可忽略，减少误配

Yandex 推荐：`smtp.yandex.com` + 端口 `587` + SSL 关（STARTTLS）+ 代理开。

### 支持的邮件服务商配置

#### Gmail
```env
SMTP_HOST=smtp.gmail.com
SMTP_PORT=587
SMTP_SSL_TYPE=  # 留空，使用STARTTLS
```

#### QQ邮箱

```env
SMTP_SSL_TYPE=ssl
```

#### 163邮箱
```env

SMTP_PORT=465
SMTP_SSL_TYPE=ssl
```

#### Outlook
```env
SMTP_HOST=smtp.office365.com
SMTP_PORT=587
SMTP_SSL_TYPE=  # 留空
```

#### 阿里云企业邮箱
```env

```

#### Yandex（国内常需代理）


## 发送邮件

### 基础 API

**文件**: `backend/utils/email.go`

```go
// EmailMessage 邮件内容结构体
type EmailMessage struct {
    To      string  // 收件人邮箱
    Subject string  // 邮件主题
    Body    string  // 邮件内容（支持HTML）
}

// SendEmail 发送邮件（自动根据配置选择SSL或非SSL）
func SendEmail(msg EmailMessage) error
```

### 基础使用示例

```go
package controllers

import (
    "fst/backend/utils"
    "fst/backend/pkg/config"
)

func (ctrl *YourController) SendNotification(c *gin.Context) {
    // 检查SMTP配置
    if config.GlobalConfig.SMTPHost == "" {
        utils.Fail(c, 500, "SMTP not configured")
        return
    }
    
    // 构造邮件
    msg := utils.EmailMessage{
        To:      "user@example.com",
        Subject: "欢迎使用我们的服务",
        Body:    "<h1>感谢您的注册</h1><p>这是一封测试邮件</p>",
    }
    
    // 发送
    if err := utils.SendEmail(msg); err != nil {
        utils.Fail(c, 500, "Failed to send email: "+err.Error())
        return
    }
    
    utils.Success(c, gin.H{"message": "Email sent successfully"})
}
```

### 使用模板发送邮件

```go
import (
    "fst/backend/app/models"
    "fst/backend/pkg/config"
    "fst/backend/utils"
    "strings"
)

func sendEmailWithTemplate(email, code string) error {
    // 获取模板
    tpl, err := models.GetEmailTemplate("register_code", "zh-CN")
    if err != nil {
        // 降级处理：使用硬编码内容
        subject := fmt.Sprintf("【%s】注册验证码", config.GlobalConfig.AppName)
        body := fmt.Sprintf("您的验证码是：%s，有效期5分钟。", code)
    } else {
        // 使用模板并替换变量
        subject = strings.ReplaceAll(tpl.Subject, "{app_name}", config.GlobalConfig.AppName)
        body = strings.ReplaceAll(tpl.Content, "{code}", code)
        body = strings.ReplaceAll(body, "{app_name}", config.GlobalConfig.AppName)
    }
    
    // 发送邮件
    return utils.SendEmail(utils.EmailMessage{
        To:      email,
        Subject: subject,
        Body:    body,
    })
}
```

## 常见使用场景

### 场景 1: 发送注册验证码

**控制器代码**: `backend/app/controllers/auth_controller.go`

```go
func (ctrl *AuthController) SendRegisterCode(c *gin.Context) {
    var req SendCodeRequest
    if err := c.ShouldBindJSON(&req); err != nil {
        utils.Fail(c, 400, err.Error())
        return
    }
    
    // 生成6位验证码
    rnd := rand.New(rand.NewSource(time.Now().UnixNano()))
    code := fmt.Sprintf("%06d", rnd.Intn(1000000))
    
    // 存储验证码，5分钟有效期
    expiresAt := time.Now().Add(5 * time.Minute)
    err := models.CreateVerificationCode(req.Email, code, "register", expiresAt)
    if err != nil {
        utils.Fail(c, 500, "Failed to generate code")
        return
    }
    
    // 获取语言
    lang := getLangFromRequest(c, req.Lang)
    
    // 获取模板
    tpl, err := models.GetEmailTemplate("register_code", lang)
    var subject, body string
    if err == nil && tpl != nil {
        subject = strings.ReplaceAll(tpl.Subject, "{app_name}", config.GlobalConfig.AppName)
        body = strings.ReplaceAll(tpl.Content, "{code}", code)
        body = strings.ReplaceAll(body, "{app_name}", config.GlobalConfig.AppName)
    } else {
        // 降级使用默认内容
        subject = fmt.Sprintf("【%s】注册验证码", config.GlobalConfig.AppName)
        body = fmt.Sprintf("您的验证码是：%s，有效期5分钟。", code)
    }
    
    // 发送邮件
    if config.GlobalConfig.SMTPHost != "" {
        err := utils.SendEmail(utils.EmailMessage{
            To:      req.Email,
            Subject: subject,
            Body:    body,
        })
        
        // 记录日志
        status := 1
        errMsg := ""
        if err != nil {
            status = 0
            errMsg = err.Error()
        }
        go func(email, subj, content string, st int, em string) {
            _ = models.CreateEmailLog(email, subj, content, "register_code", st, em)
        }(req.Email, subject, body, status, errMsg)
        
        if err != nil {
            // 开发模式返回验证码用于调试
            if config.GlobalConfig.AppMode == "dev" {
                fmt.Printf("[DEV] Email send failed. Code: %s\n", code)
            }
            utils.Fail(c, 500, "Failed to send email")
            return
        }
    }
    
    utils.Success(c, gin.H{"message": "Verification code sent"})
}
```

### 场景 2: 发送密码重置邮件

```go
func (ctrl *AuthController) SendResetEmail(c *gin.Context) {
    var req ResetEmailRequest
    if err := c.ShouldBindJSON(&req); err != nil {
        utils.Fail(c, 400, err.Error())
        return
    }
    
    // 检查邮箱是否存在
    user, err := models.GetUserByUsernameOrEmail(req.Email)
    if err != nil || user == nil {
        // 安全考虑：即使邮箱不存在也返回成功
        utils.Success(c, gin.H{"message": "If the email exists, a reset code has been sent"})
        return
    }
    
    // 生成验证码
    rnd := rand.New(rand.NewSource(time.Now().UnixNano()))
    code := fmt.Sprintf("%06d", rnd.Intn(1000000))
    
    // 存储验证码，15分钟有效期
    expiresAt := time.Now().Add(15 * time.Minute)
    _ = models.CreateVerificationCode(user.Email, code, "reset_password", expiresAt)
    
    // 构造重置链接
    frontendURL := config.GlobalConfig.FrontendURL
    if frontendURL == "" {
        frontendURL = "http://localhost:5173"
    }
    resetLink := fmt.Sprintf("%s/#/login/reset-password-confirm?email=%s&token=%s", 
        frontendURL, user.Email, code)
    
    // 获取模板
    lang := getLangFromRequest(c, req.Lang)
    tpl, err := models.GetEmailTemplate("reset_password", lang)
    var subject, body string
    if err == nil && tpl != nil {
        subject = strings.ReplaceAll(tpl.Subject, "{app_name}", config.GlobalConfig.AppName)
        body = strings.ReplaceAll(tpl.Content, "{code}", code)
        body = strings.ReplaceAll(body, "{link}", resetLink)
        body = strings.ReplaceAll(body, "{app_name}", config.GlobalConfig.AppName)
    } else {
        subject = fmt.Sprintf("【%s】密码重置请求", config.GlobalConfig.AppName)
        body = fmt.Sprintf("请点击以下链接重置密码：<br><a href=\"%s\">%s</a><br>或者使用验证码：%s<br>有效期15分钟。",
            resetLink, resetLink, code)
    }
    
    // 发送邮件并记录日志
    if config.GlobalConfig.SMTPHost != "" {
        err := utils.SendEmail(utils.EmailMessage{
            To:      user.Email,
            Subject: subject,
            Body:    body,
        })
        
        go func(email, subj, content string, st int, em string) {
            _ = models.CreateEmailLog(email, subj, content, "reset_password", st, em)
        }(user.Email, subject, body, status, errMsg)
        
        if err != nil {
            utils.Fail(c, 500, "Failed to send email")
            return
        }
    }
    
    utils.Success(c, gin.H{"message": "Reset email sent"})
}
```

## 故障排查

### 常见问题 1: 邮件发送失败

**现象**: `Failed to send email` 错误

**排查步骤**:

1. 检查 SMTP 配置
```bash
# 查看当前配置
grep -E "SMTP|EMAIL" .env
```

2. 检查网络连接
```bash
telnet smtp.gmail.com 587
```

3. 查看详细错误日志
```go
// 在 SendEmail 中添加调试
fmt.Printf("[DEBUG] SMTP Config: Host=%s, Port=%s, User=%s\n", 
    cfg.SMTPHost, cfg.SMTPPort, cfg.SMTPUser)
```

4. 确认 SSL 配置
- 端口 465：通常需要 SSL
- 端口 587：通常使用 STARTTLS，SSL 留空
- 端口 25：通常不使用 SSL

### 常见问题 2: 发件人显示不正确

**现象**: 收件人看到的发件人是邮箱地址而非名称

**解决方案**:
```env
# 确保配置了这些
SYSTEM_EMAIL_ADDRESS=noreply@yourapp.com
SYSTEM_EMAIL_NAME=YourAppName
```

代码会自动使用 MIME 编码处理中文名称：
```go
encodedName := base64.StdEncoding.EncodeToString([]byte(emailName))
fromHeader := fmt.Sprintf("=?UTF-8?B?%s?= <%s>", encodedName, fromEmail)
```

### 常见问题 3: 邮件进入垃圾箱

**解决方案**:
1. 配置 SPF 记录
2. 配置 DKIM 签名
3. 使用专业的邮件服务商（如 SendGrid、Mailgun）
4. 在邮件内容中添加退订链接

### 常见问题 4: 开发环境无法发送邮件

**解决方案**:
```go
// 开发模式下直接打印验证码到日志
if config.GlobalConfig.AppMode == "dev" {
    fmt.Printf("[DEV] Verification Code: %s\n", code)
    // 或者返回给前端（仅用于开发）
    utils.Success(c, gin.H{
        "message": "Development mode: check server logs",
        "code": code, // 仅开发环境
    })
    return
}
```

## 最佳实践

### ✅ Do's

1. **总是检查 SMTP 配置**
```go
if config.GlobalConfig.SMTPHost == "" {
    return fmt.Errorf("SMTP not configured")
}
```

2. **异步记录邮件日志**
```go
go func() {
    _ = models.CreateEmailLog(...)
}()
```

3. **使用模板系统**
- 易于维护
- 支持多语言
- 内容和代码分离

4. **提供降级方案**
```go
tpl, err := models.GetEmailTemplate(name, lang)
if err != nil {
    // 使用默认硬编码内容
}
```

5. **安全考虑**
- 不泄露邮箱是否存在
- 验证码有时效性
- 生产环境不暴露验证码到日志

### ❌ Don'ts

1. **不要同步记录日志**
```go
// 错误
models.CreateEmailLog(...) // 阻塞发送流程

// 正确
go func() {
    models.CreateEmailLog(...)
}()
```

2. **不要在生产环境暴露验证码**
```go
// 错误
utils.Success(c, gin.H{"code": code})

// 正确
utils.Success(c, gin.H{"message": "Code sent"})
```

3. **不要硬编码邮件内容**
```go
// 错误
body := "您的验证码是：123456"

// 正确
tpl, _ := models.GetEmailTemplate("register_code", lang)
body = strings.ReplaceAll(tpl.Content, "{code}", code)
```

4. **不要忽略错误处理**
```go
// 错误
_ = utils.SendEmail(msg)

// 正确
if err := utils.SendEmail(msg); err != nil {
    log.Printf("Failed to send email: %v", err)
    return err
}
```
