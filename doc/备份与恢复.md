# 备份与恢复

> 运维脚本：`tools/backup_db.ps1`、`tools/restore_db.ps1`  
> 凭据**只**从进程环境变量或仓库根目录 `.env` 读取，脚本内从不写死密码。

## 备份

在仓库根目录执行：

```powershell
# 默认读根目录 .env，备份到 ./backups，保留最近 7 天
powershell -NoProfile -ExecutionPolicy Bypass -File tools\backup_db.ps1

# 自定义保留天数 / 目录
powershell -NoProfile -ExecutionPolicy Bypass -File tools\backup_db.ps1 -KeepDays 14 -BackupDir D:\fst-backups
```

按 `DB_DRIVER` 分支：

| DB_DRIVER | 工具 | 产物示例 |
|-----------|------|----------|
| `mysql`（默认） | `mysqldump` | `backups/fst_backup_mysql_<库名>_时间戳.sql` |
| `sqlite` | 文件拷贝 | `backups/fst_backup_sqlite_时间戳.db` |
| `postgres` | `pg_dump -Fc` | `backups/fst_backup_postgres_<库名>_时间戳.dump` |

依赖：本机已安装对应客户端（`mysqldump` / `pg_dump`），并在 PATH 中。

## 恢复

```powershell
# 会提示输入 yes 确认；加 -Force 跳过确认（仅自动化场景）
powershell -NoProfile -ExecutionPolicy Bypass -File tools\restore_db.ps1 -BackupFile backups\fst_backup_mysql_fst_platform_20260101_120000.sql
```

**务必先备份再恢复。** 恢复会覆盖目标库/文件。

## 环境变量（与主程序一致）

常用键：`DB_DRIVER`、`DB_HOST`、`DB_PORT`、`DB_USER`、`DB_PASSWORD`、`DB_NAME`、`DB_PATH`（SQLite）。

进程环境变量优先于 `.env` 文件中的同名项。

## 定时任务建议（Windows）

用「任务计划程序」每天执行一次 `backup_db.ps1`，并确保运行账户能读到 `.env` 或已配置系统环境变量。生产库建议异地再留一份备份。
