# 全栈开发平台架构概览

> **最后更新**：2026-08-09

## 简介

基于 Go (Gin) + Vue 3 的全栈后台模板。原则：**数据库层 snake_case**；配置与业务解耦；插件可热扩展。

## 配置边界

| 层 | 文件 | 说明 |
|----|------|------|
| 后端进程 | 仓库根 `./.env` | 唯一主配置；打包放 exe 同级或 `../.env` |
| 前端构建 | `frontend/.env*` | Vite mode 分层，不读后端根 `.env` |
| 运行时业务 | `system_settings` | 可覆盖 SMTP/SMS 等（优先于 .env 底稿） |

详见 [配置系统.md](./配置系统.md)。

## 后端（Golang + Gin + GORM）

- Models：`backend/app/models/`，`gorm` tag + snake_case 列名
- 启动：`internal/appinit` + `internal/migrate`（AutoMigrate）+ `internal/task`
- HTTP：`routes`（public / user / admin / **ws**）
- 零件：`pkg/config` · `pkg/db` · `pkg/middleware` · **`pkg/presence`**

## 前端（Vue 3 + Vite + TypeScript）

- 双入口：用户端 / 管理端（`VITE_ADMIN_BASE_PATH`）
- 管理 API 前缀运行时由 `app-config.admin_api_path` 注入
- 登录后 Presence 心跳；Iconify 离线注册

## 数据流

数据库 snake_case → 后端 Model → JSON snake_case → 前端实体。

## 开发者手册（最短路径）

1. 改库表 → models 加 gorm tag + `AllGormModels()`，必要时在 `migrate.RunAutoMigrate` 加种子/补丁  
2. 改 API → controllers + `routes/*.go` + 前端 `service/api`  
3. 改配置键 → 根 `.env.example` + `pkg/config` + `doc/配置系统.md`  
4. 管理端文案 → 同步 `locales/zh_CN.json` 与 `en_US.json`
