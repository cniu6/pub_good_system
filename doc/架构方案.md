# Go+Vue 管理系统架构方案

本项目是基于 Go (Gin) + Vue3 的模块化**管理系统**底座。

## 1. 目录结构（当前）

```text
/fst
├── main.go / main_embedded.go   # 根入口薄壳
├── backend/
│   ├── cmd/server/              # 进程薄壳：前端托管 + Listen
│   ├── internal/
│   │   ├── appinit/             # 启动编排 Bootstrap / SetupHTTP
│   │   └── migrate/             # 全部数据库自迁移
│   ├── pkg/                     # 可复用积木：config / db连接 / middleware / pluginregistry
│   ├── app/                     # 业务 MVC：controllers / models / services / plugins
│   ├── routes/                  # SetupRoutes + public/user/admin
│   └── utils/
├── frontend/
├── tools/                       # 运维脚本（非服务入口）
├── dist/
└── .env
```

**分层口诀**：`pkg` = 零件；`internal` = 开机/建表骨架；`app` = 业务 API。不要把业务硬塞进 `internal`。

## 2. 启动链路

```text
main → cmd/server → appinit.Bootstrap → migrate.RunAutoMigrate → SetupHTTP → Listen
```
