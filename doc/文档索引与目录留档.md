## 一、顶层目录

```text
pub_good_system/
├── main.go                  # 普通构建入口（仅后端 API）
├── main_embedded.go         # embedded 构建入口（前端打进二进制）
├── go.mod / go.sum          # Go 模块（全仓库唯一 module: fst）
├── README.md                # 项目总览与快速开始
├── CLAUDE.md / rules.md     # AI 协作规则
├── .env.example             # 后端环境变量示例（本地 .env 不入库）
├── .env.production.example  # 生产环境变量示例
├── .air.toml                # 后端热重载配置（air）
├── dev.bat  / dev.sh        # 开发：扫插件 + Swagger + 前后端
├── build.bat / build.sh     # 生产构建（含 embedded）
├── test.bat / test.sh       # 测试入口（go test/vet + pnpm lint/build）
├── .github/workflows/       # CI：go test/vet + pnpm lint/build
├── .cursor/rules/           # 编辑器规则（管理端 i18n 必补等）
├── deploy/                  # Dockerfile、docker-compose、部署说明
├── doc/                     # 跨目录知识库与本文件
├── tools/                   # 运维/诊断脚本（go run，不进服务）
├── backend/                 # Go 后端
└── frontend/                # Vue 前端
```

根目录只保留**入口文件、模块文件、根脚本、全局配置示例、AI 规则**；其它脚本与文档按下文归置。

## 二、backend/

```text
backend/
├── main 入口相关
│   ├── cmd/server/          # Start()、前端资源托管（frontend.go）
│   └── internal/
│       ├── appinit/         # 启动装配（配置 → DB → 插件 → 任务）

│   ├── controllers/         # 按 {scope}/{business} 分层
│   │   ├── admin/  public/  user/  system/  v2/
│   ├── models/              # GORM 模型与查询
│   ├── services/            # 业务服务层
│   └── plugins/             # 插件实现（pay_balance、sms）
├── pkg/
│   ├── apilog/  config/  db/  middleware/
│   ├── panicsafe/  payment/  pluginregistry/  presence/
├── routes/                  # 路由汇总：public/user/admin/system/v2/ws
├── utils/                   # 通用工具（响应、分页、参数、JWT、邮件等）
├── docs/                    # swag 生成产物 docs.go（提交，勿手改）
├── static/scalar/           # Scalar 文档 UI 静态资源（入库）
```

分层约定：`controllers → services → models`；响应统一 `utils.Success` / `utils.Fail`；

## 五、归置约定

1. **根目录**只放：入口 `main.go` / `main_embedded.go`、`go.mod`、根脚本（dev/build/test）、全局配置示例、AI 规则。新增运维脚本放 `tools/`。
2. **跨目录 / 架构类文档**放 `doc/`；**单目录说明**放该目录（`留档.md` 或主题名 `.md`），不往 `doc/` 堆。
3. **新增业务目录**必须在目录内补一份说明，写清职责与入口文件。
4. **生成物**：`frontend/system-mgr/` 由 `_admin-entry` 生成，不入库；`backend/docs/docs.go` 由 swag 生成但**必须提交**（编译依赖），也不要手改。
5. **包管理器**：前端只用 pnpm，锁文件只保留 `pnpm-lock.yaml`。
6. 本地 `.env`、数据库文件、日志、WAL 不入库；示例统一用 `*.example`。
7. 与源码冲突时以源码为准，并回写文档；重要改动同步更新本文件的日期与「整理记录」。
