# 数据库模型

> **最后更新**：2026-08-09  
> 关联：`backend/pkg/db/` · `backend/app/models/` · `backend/internal/migrate/` · `backend/pkg/config/`

---

## 架构

```
Controller → Service → Model（GORM API） → mysql / sqlite / postgres
```

| 组件 | 路径 | 说明 |
|------|------|------|
| 连接 | `pkg/db/db.go` | `gorm.Open`，导出 `DB *gorm.DB` |
| 小工具 | `pkg/db/gorm_helpers.go` | `ForUpdate` / `WithTx` / `MapGormNotFound` |
| 迁移 | `internal/migrate/auto_migrate.go` | **唯一**编排：`AutoMigrate` + 种子/补丁 |
| 模型清单 | `app/models/gorm_models.go` | `AllGormModels()` |
| 配置 | `pkg/config` | `DB_DRIVER` + DSN（根目录 `.env`） |

软删三套并存（**不用**默认 `gorm.DeletedAt`）：

- 多数业务表：`delete_time IS NULL`
- `verification_codes`：`is_deleted`
- `announcements`：`deleted_at = 0`

## 配置

根目录 `.env`：

```env
DB_DRIVER=mysql   # mysql | sqlite | postgres
DB_HOST=127.0.0.1
DB_PORT=3306
DB_USER=root
DB_PASSWORD=
DB_NAME=fst_platform
# SQLite 可用 DB_PATH=data/fst.db
```

DSN 由 `pkg/config` 组装；SQLite 驱动为 `github.com/glebarez/sqlite`（纯 Go）。

## 连接与迁移

```go
import (
    "fst/backend/pkg/config"
    "fst/backend/pkg/db"
    "fst/backend/internal/migrate"
)

config.InitConfig()
db.InitDB()                 // 只连库 + 连接池，不建表
migrate.RunAutoMigrate()    // AutoMigrate(AllGormModels) + 种子/补丁
```

业务代码一律通过 `db.DB`（`*gorm.DB`）或已有 `models.*` 函数访问，**不要**再写方言层 / sqlx。

## 模型约定

```go
type User struct {
    ID         uint64  `gorm:"column:id;primaryKey;autoIncrement" json:"id"`
    Username   string  `gorm:"column:username;size:100;uniqueIndex" json:"username"`
    CreateTime *int64  `gorm:"column:create_time" json:"create_time"`
    UpdateTime *int64  `gorm:"column:update_time" json:"update_time"`
    DeleteTime *int64  `gorm:"column:delete_time" json:"-"`
    // ...
}

func (u *User) TableName() string { return "users" }
```

- 列名 snake_case；JSON 对外也用 snake_case
- 时间多为 Unix `int64` / `*int64`（`system_settings` 等例外用 `time.Time`）
- 对外仍保留 `GetUserByID`、`CreatePaymentOrder` 等函数名，内部实现为 GORM

新增表：给 struct 加 gorm tag → 加入 `AllGormModels()` → 必要时在 `RunAutoMigrate` 加种子/补丁。

## CRUD（优先复用 models）

```go
user, err := models.GetUserByID(id)
err = models.CreateUser(user)
err = models.UpdateUser(user)
```

直接用 GORM 时：

```go
var user models.User
err := db.DB.Where("id = ? AND delete_time IS NULL", id).First(&user).Error
err = db.DB.Create(&user).Error
err = db.DB.Model(&user).Updates(map[string]interface{}{"nickname": "x"}).Error
```

未找到映射：`db.MapGormNotFound` / `errors.Is(err, gorm.ErrRecordNotFound)` → 常转成 `sql.ErrNoRows` 以兼容旧调用方。

## 事务与行锁

```go
err := db.DB.Transaction(func(tx *gorm.DB) error {
    var order models.PaymentOrder
    if err := db.ForUpdate(tx).Where("id = ?", id).First(&order).Error; err != nil {
        return err
    }
    // ...
    return nil
})

// 或封装
err := db.WithTx(func(tx *gorm.DB) error { ... })
```

余额变动统一走 `utils.ExecuteBalanceOpTx(tx *gorm.DB, ...)`。

唯一冲突：`db.IsDuplicateKeyError(err)`；upsert：`clause.OnConflict{...}`。

## 最佳实践

1. **不要**在业务里手拼跨方言 SQL；复杂逻辑放 models/services
2. 控制器不直接碰 `db.DB`，走 service → model
3. 禁止业务接口 `c.JSON(4xx)` / `gin.H{"error"}`，用 `utils.Success` / `utils.Fail`
4. 换库只改 `DB_DRIVER` + DSN；Postgres 上生产前用真实实例跑迁移 + 支付/提现冒烟
