## 配置结构

### Config 结构体

**文件**: `backend/pkg/config/config.go`

```go
type Config struct {
    // 应用信息
    AppName  string  // 应用名称
    AppTitle string  // 应用标题
    AppMode  string  // 运行模式 (separate/embedded)
    
    // 服务器
    Port string  // 监听端口
    HTTPReadHeaderTimeoutSeconds int // 请求头读取超时（秒）
    HTTPReadTimeoutSeconds       int // 请求读取超时（秒）
    HTTPWriteTimeoutSeconds      int // 响应写入超时（秒）
    HTTPIdleTimeoutSeconds       int // Keep-Alive 空闲超时（秒）
    HTTPShutdownTimeoutSeconds   int // 优雅关闭等待超时（秒）
    HTTPMaxHeaderBytes           int // 请求头最大字节数
    
    // 数据库
    DBDriver string  // 数据库驱动
    DBDSN    string  // 数据库连接串
    
    // 极验验证码
    GeetestEnabled bool   // 是否启用
    GeetestID      string // 极验ID
    GeetestKey     string // 极验密钥
    
    // JWT
    JWTSecret string // JWT签名密钥
    
    // 管理端：页面入口 vs REST 前缀（分离）
    AdminPath    string // ADMIN_PATH，如 /system-mgr
    AdminAPIPath string // ADMIN_API_PATH，如 /admin → /api/v1/admin
    
    // CORS
    CorsOrigins string // 允许的跨域源
    
    // Swagger / 高危运维
    EnableSwagger       bool // ENABLE_SWAGGER
    EnableAdminDebugOps bool // ENABLE_ADMIN_DEBUG（生产强制 false）
    
    // 前端
    FrontendURL string // 前端URL
    
    // SMTP
    SMTPHost        string // SMTP服务器
    SMTPPort        string // SMTP端口
    SMTPUser        string // SMTP用户名
    SMTPPass        string // SMTP密码
    SMTPSSL         bool   // 是否使用SSL
    SystemEmail     string // 系统发件邮箱
    SystemEmailName string // 系统发件人名称
}

// 全局配置实例
var GlobalConfig *Config
```

### 初始化代码

**文件**: `backend/pkg/config/config.go`

```go
// InitConfig 初始化配置
func InitConfig() {
    // 优先尝试 JSON 格式
    if cfg, ok := loadJSONDotEnv(".env"); ok {
        GlobalConfig = cfg
        return
    }
    
    // 回退到标准 .env 格式
    if err := godotenv.Load(); err != nil {
        log.Println("Error loading .env file, using default environment variables")
    }
    
    // 构建配置
    GlobalConfig = &Config{
        AppName:  getEnv("APP_NAME", "F.st"),
        AppTitle: getEnv("APP_TITLE", "F.st - Think Fast,Run F.st"),
        AppMode:  getEnv("APP_MODE", "separate"),
        Port:     getEnv("PORT", "8080"),
        DBDriver: getEnv("DB_DRIVER", "mysql"),
        DBDSN:    buildDSN(),
        // ... 其他配置
    }
}
```

#### HTTP 服务超时与慢连接防护

Go 标准库的 `http.ListenAndServe` 默认不会替你设置 `ReadHeaderTimeout`、`ReadTimeout`、`WriteTimeout`、`IdleTimeout`。在纯正常流量下，这看起来只是“少一点检查开销”；但一旦遇到慢连接、慢请求头或 Slowloris 一类攻击，连接会长时间占住 goroutine、fd 和请求处理队列，尾延迟会迅速恶化。

当前仓库已将启动入口统一切到显式 `http.Server`，默认值采用一组可直接用于生产的基线：

- `ReadHeaderTimeout = 5s`
- `ReadTimeout = 5s`
- `WriteTimeout = 10s`
- `IdleTimeout = 120s`
- `MaxHeaderBytes = 1MB`

几个参数各自负责的面向不同：

- `ReadHeaderTimeout`：限制请求头读取时间，是防御慢请求头攻击的首要参数。
- `ReadTimeout`：限制从开始读请求到请求体读取完成的总时间。
- `WriteTimeout`：限制服务端写响应的总时间，避免慢客户端反向拖住连接。
- `IdleTimeout`：限制 Keep-Alive 空闲连接可存活的时长，避免大量空闲连接长期占用资源。
- `HTTP_SHUTDOWN_TIMEOUT_SECONDS`：配合 `srv.Shutdown(ctx)` 做优雅关闭，避免直接退出截断进行中的请求。

## 配置使用

### 基本使用

```go
package controllers

import (
    "fst/backend/pkg/config"
)

func SomeHandler(c *gin.Context) {
    // 访问全局配置
    port := config.GlobalConfig.Port
    appName := config.GlobalConfig.AppName
    
    // 检查功能是否启用
    if config.GlobalConfig.GeetestEnabled {
        // 处理验证码
    }
    
    // 使用配置值
    email := utils.EmailMessage{
        To: user.Email,
        Subject: config.GlobalConfig.AppName + " - 验证码",
    }
}
```

### 配置检查模式

```go
// CheckMode 检查运行模式
func CheckMode() string {
    return config.GlobalConfig.AppMode
}

// IsDev 检查是否为开发模式
func IsDev() bool {
    return config.GlobalConfig.AppMode != "production"
}

// IsProduction 检查是否为生产模式
func IsProduction() bool {
    return config.GlobalConfig.AppMode == "production"
}
```

### 动态配置（热更新）

```go
package config

import (
    "sync"
    "time"
)

var (
    configMutex sync.RWMutex
    lastReload  time.Time
)

// ReloadConfig 重新加载配置
func ReloadConfig() error {
    configMutex.Lock()
    defer configMutex.Unlock()
    
    cfg, err := loadConfigFromFile()
    if err != nil {
        return err
    }
    
    GlobalConfig = cfg
    lastReload = time.Now()
    
    return nil
}

// GetConfig 线程安全地获取配置
func GetConfig() *Config {
    configMutex.RLock()
    defer configMutex.RUnlock()
    return GlobalConfig
}
```

### 3. 配置验证

```go
func (c *Config) Validate() error {
    // 验证必需配置
    if c.JWTSecret == "" || c.JWTSecret == "secret" {
        return fmt.Errorf("JWT_SECRET is required and must not be default value")
    }
    
    // 验证数据库配置
    if c.DBDSN == "" {
        return fmt.Errorf("database DSN is required")
    }
    
    // 验证端口范围
    port, _ := strconv.Atoi(c.Port)
    if port < 1 || port > 65535 {
        return fmt.Errorf("invalid port number: %s", c.Port)
    }
    
    return nil
}

// 在 InitConfig 中调用
func InitConfig() {
    // ... 加载配置
    
    if err := GlobalConfig.Validate(); err != nil {
        log.Fatalf("Config validation failed: %v", err)
    }
}
```

### 4. 环境区分

```go
func loadEnvFile() {
    env := os.Getenv("APP_ENV")
    if env == "" {
        env = "development"
    }
    
    envFile := fmt.Sprintf(".env.%s", env)
    
    // 尝试加载环境特定配置
    if _, err := os.Stat(envFile); err == nil {
        godotenv.Load(envFile)
        log.Printf("Loaded config from %s", envFile)
    } else {
        godotenv.Load(".env")
    }
}
```
